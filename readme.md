Inspired by the game Jawbreaker, which is used as a practice project in “Java ist auch eine Insel” by Christian Ullenboom.

The purely Java-based Laterna TextGUI is used.

The structure of this remote repository is a bit special due to directories such as _POMS_forMavenNature.
This is because it is meant to be a clear base for different local project natures.
In fact, I use this remote repository to synchronize two local repos, a pure Java project and a Java-Maven project.
